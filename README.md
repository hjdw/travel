# 🌟 여행 추억 홈페이지

전국 여행의 소중한 순간들을 기록하고 관리하는 아름다운 웹 애플리케이션입니다.

## ✨ 주요 기능

- **여행 추억 추가**: 제목, 장소, 날짜, 설명, 이미지, 평점을 포함한 여행 기록
- **추억 편집**: 기존 여행 추억 수정
- **추억 삭제**: 불필요한 추억 제거
- **평점 시스템**: 5점 만점의 별점 평가
- **반응형 디자인**: 모바일과 데스크톱에서 모두 최적화된 UI
- **애니메이션**: 부드러운 전환 효과와 인터랙션

## 🛠️ 기술 스택

- **React 18** - 사용자 인터페이스 구축
- **TypeScript** - 타입 안전성과 개발 경험 향상
- **Styled Components** - CSS-in-JS 스타일링
- **Framer Motion** - 부드러운 애니메이션
- **React Icons** - 아이콘 라이브러리

## 🚀 시작하기

### 필수 요구사항

- Node.js 16.0.0 이상
- npm 또는 yarn

### 설치 및 실행

1. **의존성 설치**
   ```bash
   npm install
   ```

2. **개발 서버 실행**
   ```bash
   npm start
   ```

3. **브라우저에서 확인**
   - http://localhost:3000 으로 접속

### 빌드

프로덕션용 빌드를 생성하려면:

```bash
npm run build
```

## 📱 사용법

1. **새 추억 추가**
   - "새 추억 추가" 버튼 클릭
   - 제목, 장소, 날짜, 이미지 URL, 설명 입력
   - 별점으로 만족도 평가
   - "추가하기" 버튼으로 저장

2. **추억 편집**
   - 추억 카드의 편집 아이콘(연필) 클릭
   - 원하는 정보 수정
   - "수정하기" 버튼으로 저장

3. **추억 삭제**
   - 추억 카드의 삭제 아이콘(휴지통) 클릭

## 🎨 디자인 특징

- **그라데이션 배경**: 보라색 계열의 아름다운 그라데이션
- **글래스모피즘**: 반투명 효과와 블러 처리
- **카드 레이아웃**: 깔끔한 카드 형태의 정보 표시
- **호버 효과**: 마우스 오버 시 부드러운 애니메이션
- **반응형 그리드**: 화면 크기에 따라 자동 조정
